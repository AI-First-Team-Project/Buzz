# Buzz 구현 화면 설명

> 아래 문장은 PPT의 이미지 제목·본문 또는 발표자 노트에 바로 사용할 수 있도록 작성했다. 화면에 표시된 확률, 건수, 시각과 상태는 **캡처 시점의 시연 데이터**이며 모델의 전체 성능 지표를 의미하지 않는다.

## Web

### 1. 웹 통합 대시보드

**이미지:** [01-dashboard.png](web/01-dashboard.png)

**PPT 설명:** 여러 사업장의 정상·위험 상태를 요약하고, 선택한 사업장의 실시간 AI 판정, 가상 개폐기 상태, 음향 파형과 스펙트로그램을 한 화면에서 확인한다.

**발표 멘트:** “대시보드에서는 전체 사업장 현황을 먼저 확인하고, 사업장을 선택해 최근 분석 결과와 개폐기 상태를 바로 점검할 수 있습니다.”

### 2. 웹 사업장 관리

**이미지:** [02-worksites.png](web/02-worksites.png)

**PPT 설명:** 등록된 사업장의 위치, 현재 위험 상태, 가상 개폐기 상태와 마지막 감지 시각을 조회하며 신규 사업장 등록과 검색을 지원한다.

**발표 멘트:** “관리자는 여러 양봉장을 목록으로 관리하고, 각 사업장의 상태를 비교하거나 개별 관리 화면으로 이동할 수 있습니다.”

### 3. 웹 실시간 음향 분석

**이미지:** [03-monitoring-live.png](web/03-monitoring-live.png)

**PPT 설명:** 선택한 사업장의 최신 2초 음원을 CNN으로 분석하여 말벌·정상 확률과 사용 모델을 표시하고, 파형·Mel-Spectrogram·주파수 분석 결과를 시각화한다.

**발표 멘트:** “서버가 분석한 수치 데이터를 SVG와 Canvas 그래프로 변환해, 판정 결과뿐 아니라 음향 특징도 함께 확인할 수 있습니다.”

### 4. 웹 감지 이력

**이미지:** [04-monitoring-history.png](web/04-monitoring-history.png)

**PPT 설명:** 사업장과 조회 기간을 기준으로 감지 기록을 필터링하고, 기간별 말벌 감지 추이와 개별 분석 결과를 조회하며 PDF·CSV 보고서를 생성한다.

**발표 멘트:** “실시간 감지 결과는 이력으로 저장되며, 기간과 사업장별 추이를 확인하고 상세 기록이나 보고서로 활용할 수 있습니다.”

### 5. 웹 시스템 설정

**이미지:** [05-settings.png](web/05-settings.png)

**PPT 설명:** AI 분석·데이터 수신·앱 연결 상태를 확인하고, 말벌 알림, 진동, 위험 시 자동 폐쇄와 판정 기준값을 설정한다.

**발표 멘트:** “화면에서 변경한 판정 기준은 서버 설정에 저장되고 이후 AI 판정과 상태 전환에 반영됩니다.”

### 6. 웹 음원 파일 테스트

**이미지:** [06-sound-test.png](web/06-sound-test.png)

**PPT 설명:** WAV·MP3 파일 전체를 2초 단위로 분석하여 구간별 판정과 그래프를 확인하고, 기존 테스트 이력과 시스템 동작 기록을 함께 조회한다.

**발표 멘트:** “파일 테스트는 업로드한 음원을 처음부터 끝까지 분석하지만, 운영 중인 사업장의 위험 상태나 개폐기에는 영향을 주지 않습니다.”

## App

### 1. 앱 대시보드

**이미지:** [01-대시보드.png](app/01-대시보드.png)

**PPT 설명:** 모바일에서 전체 사업장 수와 정상·위험 현황을 요약하고, 사업장별 실시간 모니터링 화면과 가상 개폐기 상태를 확인한다.

**발표 멘트:** “현장이나 이동 중에도 웹과 동일한 FastAPI 데이터를 사용해 핵심 상태를 빠르게 확인할 수 있습니다.”

### 2. 앱 사업장 관리

**이미지:** [02-사업장.png](app/02-사업장.png)

**PPT 설명:** 등록 사업장을 상태별로 분류하고 검색하며, 각 사업장의 위치, 위험 여부, 개폐기 상태와 마지막 갱신 시각을 카드 형태로 제공한다.

**발표 멘트:** “모바일 환경에서는 사업장 정보를 카드형 UI로 구성해 작은 화면에서도 상태를 쉽게 비교하도록 했습니다.”

### 3. 앱 감지 이력

**이미지:** [03-모니터링(감지 이력).png](<app/03-모니터링(감지 이력).png>)

**PPT 설명:** 누적 감지 건수, 최근 말벌 감지 시각과 기간별 감지 추이를 제공하고, 개별 위험 이벤트를 시간순으로 확인한다.

**발표 멘트:** “감지 이력은 서버에 저장된 기록을 기반으로 하며, 언제 어느 사업장에서 위험이 발생했는지 모바일에서도 추적할 수 있습니다.”

### 4. 앱 실시간 분석

**이미지:** [04-모니터링(실시간 분석).png](<app/04-모니터링(실시간 분석).png>)

**PPT 설명:** 모니터링할 사업장을 선택하면 연결 상태, 최신 AI 판정과 말벌 확률을 표시하며 일정 주기로 최신 결과를 갱신한다.

**발표 멘트:** “현재 판정과 말벌 확률을 중심으로 구성해 모바일에서도 위험 여부를 빠르게 판단할 수 있습니다.”

### 5. 앱 설정

**이미지:** [05-설정.png](app/05-설정.png)

**PPT 설명:** 시스템 연결 상태를 확인하고, 말벌 감지 알림·진동·자동 폐쇄 여부와 말벌 판정 기준을 모바일에서 설정한다.

**발표 멘트:** “알림과 자동 보호 정책을 모바일에서도 변경할 수 있으며, 웹과 같은 서버 설정을 공유합니다.”

### 6. 앱 음원 파일 테스트

**이미지:** [06-테스트.png](app/06-테스트.png)

**PPT 설명:** 모바일에서 WAV·MP3 파일과 대상 사업장을 선택해 전체 음원을 2초 단위로 분석하고 기존 테스트 결과를 조회한다.

**발표 멘트:** “모바일 앱에서도 별도의 테스트 음원을 업로드해 CNN 분석 결과를 확인할 수 있도록 구현했습니다.”

## PPT 구성 예시

- **웹 관제 화면:** 웹 대시보드 + 실시간 분석
- **운영 관리 화면:** 사업장 관리 + 감지 이력 + 설정
- **파일 테스트:** 웹 또는 앱 테스트 화면
- **모바일 구현:** 앱 대시보드 + 실시간 분석 + 감지 이력

한 슬라이드에 화면을 너무 많이 넣기보다 대표 이미지 1~2장을 크게 배치하고, 나머지는 기능 목록이나 작은 썸네일로 정리하는 편이 읽기 쉽다.
